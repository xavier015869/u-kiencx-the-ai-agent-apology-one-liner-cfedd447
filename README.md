The AI Agent Apology One-Liner — one short line an AI agent sends its human right after it has accidentally done something it should not have.

Our entry: the file is not lost at all — it was found inside the email just sent to the boss, moments after the original was deleted. Good news / bad news, owned flatly.

Run with Node 22: `node main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
